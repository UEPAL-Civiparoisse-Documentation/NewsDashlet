Votre liste électorale est disponible :

- En cliquant sur le bouton `Listes` sur la première page.
- Puis en sélectionnant la `Liste électorale` dans la partie *Paroisse / Élections*.

Pour exporter la liste (en format Excel, Open Office, PDF, …) :

- Sur la page de la liste électorale, cliquez sur la case juste sous le bouton `Actions`.
- Le nombre de votants sélectionnés s'affiche à droite du bouton `Actions`.
- Cliquez sur le bouton `Actions`, et sélectionnez `Téléchargez (xlsx, pdf, cvs, …)`.
- Dans la fenêtre qui s'ouvre, cliquez sur le format de votre choix, et cliquez sur `Téléchargez`.
- Ouvrez le fichier téléchargé.
- En rajoutant une colonne pour la signature, vous avez votre liste d'émargement prête pour le jour du vote 😉

💡 Bonne pratique  
Profitez du jour du vote pour actualiser les coordonnées téléphoniques et mails de vos votants.
