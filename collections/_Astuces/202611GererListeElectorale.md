Nous vous invitons à procéder en deux étapes.  
Premièrement, vérifiez que tous vos paroissiens ont un lien avec la paroisse. Pour cela :

* Cliquez sur le bouton `Contrôles` sur la première page.
* Vérifiez que les listes suivantes indiquent un chiffre à zéro (ou le plus proche possible de zéro) :
    - Individus sans lien avec la Paroisse
    - Individus Majeurs avec Statut Enfant
    - Foyers avec Statut Adhésion
    - Organisation avec Statut Adhésion
* Si ce n'est pas le cas, cliquez sur chaque liste et suivez les instructions indiquées en haut de chaque page.
* Et si ce n'est pas déjà fait, créez les fiches Foyers et Individus de vos nouveaux arrivants.

Deuxièmement, passez en revue la liste électorale pour enlever les anciens votants. Pour cela :

* Cliquez sur le bouton `Listes` sur la première page.
* Sélectionnez la `Liste électorale` dans la partie *Paroisse / Élections*.
* Parcourez la liste électorale pour identifier des personnes encore inscrites alors qu'elles ne sont plus votants. Pour information, les personnes décédées sont automatiquement enlevées de la liste électorale.

Pour enlever une personne de la liste électorale :

* Ouvrez sa fiche.
* Cliquez sur le bouton `Adhésions`.
* Cliquez sur le menu à droite de la ligne indiquant le statut Électeur.
* Choisissez `Update Membership`.
* Renseignez une date de fin. La date du jour peut convenir, ou une date antérieure si vous en avez connaissance.
* Dans le menu `Forcer le statut`, sélectionnez la ligne `Forcer / Outrepasser de façon permanente` afin que son statut soit modifié dans les listes.
* Dans le menu `Statut de l'adhésion`, sélectionnez *Annulé*, puis validez.
* Afin de conserver l'historique du lien avec la paroisse, n'utilisez jamais le menu `Supprimer l'adhésion`.
